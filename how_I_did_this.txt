⏺ simonw/llm

  LLM is a command-line tool and Python library by Simon Willison that
  provides unified access to multiple large language models.

  Key Features

  - Multi-provider support: OpenAI, Anthropic Claude, Google Gemini, Meta
  Llama, and dozens more
  - Local & remote: Works with both API-based models and locally-installed
  models
  - Multi-modal: Supports text, images, audio, and video
  - SQLite logging: All interactions are logged to a local database
  - Embeddings: Extract and store vector embeddings
  - Structured output: Generate JSON using schemas
  - Tool use: Grant models tool-use capabilities
  - Plugin architecture: Extensible via community plugins
  - Templates: Reusable prompt templates
  - Fragments: Long-context support

  Installation

  pip install llm
  # or
  brew install llm
  # or
  pipx install llm
  # or
  uv tool install llm

  Basic Usage

  # Set API key
  llm keys set openai

  # Run a prompt
  llm "your prompt here"

  # Interactive chat
  llm chat

  Stats

  - ⭐ 10.4k GitHub stars
  - 📄 Apache 2.0 license

  It's a popular tool for developers who want CLI access to LLMs with
  logging, templates, and plugin extensibility.

⏺ The llm tool supports the OPENAI_API_KEY environment variable but doesn't
  natively read .env files. Here's how to make it work:

  Option 1: Source your .env file first

  # If your .env has: OPENAI_API_KEY=sk-...
  source .env
  llm "your prompt"

  Option 2: Use dotenv CLI

  # Install dotenv-cli
  npm install -g dotenv-cli

  # Run llm with .env loaded
  dotenv llm "your prompt"

  Option 3: Export inline

  export $(cat .env | xargs) && llm "your prompt"

  Option 4: Add to shell profile

  Add source /path/to/.env to your ~/.zshrc or ~/.bashrc.

  ---

  As of my knowledge cutoff (January 2025), GPT-5 hasn't been released. The
  latest OpenAI models are:

  - gpt-4o (default)
  - gpt-4-turbo
  - gpt-4
  - o1, o1-mini, o1-preview (reasoning models)

  To specify a model:

  llm -m gpt-4o "your prompt"
  # or
  llm -m o1 "your prompt"

  List available models:

  llm models

⏺ Install the Gemini plugin

  llm install llm-gemini

  Set your API key

  llm keys set gemini
  # Enter your Google AI API key when prompted

  Or via environment variable in your .env:
  GEMINI_API_KEY=your-key-here

  Then:
  source .env

  Use Gemini

  # List available Gemini models
  llm models | grep -i gemini

  # Run a prompt
  llm -m gemini-2.0-flash "your prompt"

  Verify installation

  llm plugins
